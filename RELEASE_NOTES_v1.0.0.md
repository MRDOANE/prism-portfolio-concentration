# v1.0.0 - Beyond Independent Shots on Goal

Initial public release of the PRISM portfolio concentration simulation and the
reference results supporting *Beyond Independent Shots on Goal: Risk Capacity,
Synergy, and Concentration in Pharmaceutical R&D Portfolios*.

## Included

- Simulation library for independent, PIAP, and MSOG portfolio structures.
- Locked flat-benchmark and matched-heterogeneity configurations.
- Technical-dependence, R&D-synergy, staging, launch-service, cannibalization,
  and decision-regret analyses.
- Complete reference result tables and publication figures.
- Exact Gaussian-factor integration and Monte Carlo boundary confirmation.
- Unit tests, numerical validation reports, and one-command reproduction
  scripts.
- TIRS-formatted research article and supplementary material for version
  matching.

## Reference run

- 1,000 matched heterogeneous opportunity sets.
- 4,096 exact realized states per opportunity set and topology cell.
- 250,000-path confirmation for eight near-boundary cells.
- All prespecified E4-E8 validation checks passed.

The repository contains simulated data and published aggregate scenario
anchors. It contains no patient-level or confidential company data.
